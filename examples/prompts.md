# 调用示例

## 1. 挖掘一个国家的高利润项目

```text
$mine-cross-border-private-projects

帮我针对马来西亚华人挖掘 10 个适合 TikTok 获客、
WhatsApp 私域成交的高利润项目。

要求：
1. 客单价最好在 3000 元人民币以上；
2. 当地稀缺；
3. 可以定制或者卖服务；
4. 调研 TikTok 做的人多不多；
5. 区分内容创作者、公开卖家和私域竞争者；
6. 给出竞争分、需求证据分和变现空位分；
7. 选出最值得测试的 3 个项目。
```

## 2. 评估一个具体项目

```text
$mine-cross-border-private-projects

评估“面向外国人的中国茶酥线上培训”。

目标市场：美国
目标用户：喜欢中国文化、想做家庭烘焙或小生意的人

重点分析：
1. TikTok 相关内容和账号多不多；
2. 真正卖课程的人有多少；
3. 评论区有没有学习、配方、原料替代和开店需求；
4. 项目的竞争度和变现空位；
5. 应该卖单课、完整课程、材料包还是商业培训；
6. 设计 10 条测试视频。
```

## 3. 比较多个赛道

```text
$mine-cross-border-private-projects

比较以下项目：
1. 英文中国小吃培训；
2. 定制旗袍；
3. 新中式家居软装；
4. 中国婚礼用品定制。

目标市场：新加坡和马来西亚。
按照需求强度、TikTok 竞争度、利润、交付难度和私域成交价值排序。
```

## 4. 从现有 TikTok 账号换品

```text
$mine-cross-border-private-projects

我有一个 5000 粉丝的 TikTok 账号，内容是潮汕竹编灯笼和潮汕摆件，
多条视频播放过万，部分超过 10 万，但灯笼咨询少、摆件利润低。

请根据现有人群和内容标签，推荐可以自然换品的高利润产品或服务，
并研究 TikTok 竞争情况、转型内容和私域报价。
```

## 5. 分析非标定制项目

```text
$mine-cross-border-private-projects

请分析企业奖杯/纪念品和小品牌定制包装，
分别针对东南亚、台湾、欧美、日韩市场拆解。

重点研究：
- 哪些细分场景客单价高；
- TikTok 做内容和销售的人多不多；
- 哪些需求适合先收设计费；
- 中国供应链优势；
- 国际物流和售后难点；
- 最适合测试的市场与内容方向。
```
